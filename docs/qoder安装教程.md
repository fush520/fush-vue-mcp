# Qoder 安装教程

本教程将指导您完成 Qoder 与 Fush 插件的配置过程。

---

## 一、下载与安装 Qoder

1. 访问官网 [https://qoder.com/](https://qoder.com/) 下载并安装 Qoder
2. 登录您的账号
3. 打开任意一个项目

---

## 二、安装 Fush Vue MCP 插件

您可以选择以下任一方式安装浏览器插件：

### 方式一：从源码安装

1. 下载或克隆项目到本地
2. 打开 Chrome 浏览器，访问 `chrome://extensions/`
3. 开启右上角的「开发者模式」
4. 点击「加载已解压的扩展程序」
5. 选择源码文件夹即可

### 方式二：从 Release 下载

> ⚠️ 本项目**尚未发布 Release**——目前只有「方式一：从源码安装」这一条路。

### 安装 MCP 服务依赖（会自动构建）

```bash
# 进入 MCP 服务器目录
cd /你的路径/Fush/mcp-server

# 安装依赖 —— 结束时自动跑 prepare → npm run build，产出 dist/
npm install
```

> 💡 **装完请确认 `mcp-server/dist/index.bundle.cjs` 存在**——不存在说明构建那步失败了，
> 往上翻 npm 的输出找报错。也可以手动补跑一次：`npm run build`。

---

## 三、配置 MCP 服务

### 步骤 1：添加 MCP 服务器

点击右上角 **设置** → 找到 **MCP 服务** → 点击 **添加**

### 步骤 2：编辑 mcp.json 配置文件

系统会自动打开 `mcp.json` 文件，填入以下配置代码：

```json
{
  "mcpServers": {
    "Fush": {
      "command": "node",
      "args": ["/你的地址/Fush/mcp-server/dist/index.bundle.cjs"],
      "env": {
        "MCP_PORT": "9527"
      }
    }
  }
}
```

> ⚠️ **注意事项：**
> - 将 `/你的地址/` 替换为您实际的安装路径
> - `MCP_PORT` 端口号必须与插件配置保持一致
> - 配置完成后按 `Ctrl + S` 保存文件

### 步骤 3：启用 MCP 服务

1. 返回 **MCP 服务器** 页面
2. 找到名为 `Fush` 的服务
3. 点击启用按钮
4. 首次启用时会跳转到智能体对话页面，此时可能显示"未连接"状态

---

## 四、配置浏览器插件

### 步骤 1：启用 MCP 功能

1. 打开已安装的 Fush Vue MCP 插件设置页面
2. 找到 MCP 配置选项并开启
3. 确保端口号与 `mcp.json` 中配置的端口一致（如：`9527`）
4. 点击 **启动 MCP**

### 步骤 2：确认连接状态

等待片刻后，插件应显示：

> ✅ **状态：已连接（端口：9527）**

---

## 五、验证配置

配置完成后，随意打开一个网站，然后回到 Qoder 对话页面进行测试。

**测试命令：**
```
请帮我调用 Fush 获取当前网站的 title 标题
```

如果配置正确，将成功返回当前网页的标题信息。

---

## 🎉 配置完成

恭喜！至此 Qoder 与 Fush 的配置已全部完成，您现在可以开始使用了！

---

## 常见问题

| 问题 | 解决方案 |
|------|----------|
| 显示"未连接"状态 | 检查端口号是否与插件配置一致 |
| MCP 服务启动失败 | 确认 Node.js 已正确安装，路径配置正确 |
| 插件无法连接 | 尝试重启浏览器和 Qoder |
